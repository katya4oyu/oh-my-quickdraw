# Comparison table and pros / cons

Options side by side over the same points. A few rows: a `markdown` card with a table. More, or to draw it as people would: one SVG — a column for the point names and one per option, a row per point (`rect`s with a `text` in each, 14 px), a `<g>` per row so it is drawn row by row. The winner of each row: bold green (`stroke-width` 5) or `pen circle` on it afterwards.

Pros / cons: two columns (green: for, red: against), one keyword per line, and the conclusion under both.
