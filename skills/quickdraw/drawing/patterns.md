# Diagram patterns

Pick the pattern from the relation (`visual-thinking.md`, Think), then read only its file: what it is for, its shape, and its units: `apply` skeletons to adapt, one unit of thought each, drawn one after another with the same `origin` (replace the words, widen the shapes for longer ones). `Q_ID` and the like: the id an earlier unit's `placed` gave for that ref.

| Pattern | For | File |
|---|---|---|
| Flow | steps in order, with choices (diamonds) | `patterns/flow.md` |
| Timeline | events at points in time | `patterns/timeline.md` |
| Journey | stages × what a person does, feels, where it hurts | `patterns/journey.md` |
| Cause chain and loop | A leads to B leads to C; a vicious or virtuous circle | `patterns/cause-chain-and-loop.md` |
| Tree | a breakdown, why-why, an issue tree | `patterns/tree.md` |
| 2x2 matrix | items sorted by two qualities | `patterns/2x2-matrix.md` |
| Comparison table, pros / cons | options side by side over the same points | `patterns/comparison-table-and-pros-cons.md` |
| Decision | a question, its options and costs, the one chosen | `patterns/decision.md` |
| Venn | what two or three things share | `patterns/venn.md` |
| Mind map | one topic, its parts around it | `patterns/mind-map.md` |
| Pyramid | levels, the base widest | `patterns/pyramid.md` |
| Affinity groups | many loose items sorted into named groups | `patterns/affinity-groups.md` |
